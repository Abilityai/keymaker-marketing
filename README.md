# Keymaker Marketing

The marketing desk of **Keymaker**, an agency that sets up automation on Trinity for other
companies. One of the Keymaker agency starter templates, built in public during the
[Agent-Native Agency workshop](https://www.ability.ai/trinity/workshops/agent-native-agency-workshop).

Plans the content, counts the leads by channel, writes the weekly report, and hands qualified
inbound to Keymaker Sales.

## Install

**Library → Agents → Keymaker Marketing → Create**, or `template: github:Abilityai/keymaker-marketing`.
No credentials needed.

## Playbooks

- `/content-plan` - the next two weeks, each item tied to an offer
- `/weekly-report` - leads by channel, content shipped, one change for next week

Assign `one-pager` or `presentation` from the Skills Library to make sales material.
